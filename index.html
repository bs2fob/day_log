🔑 GitHub 연동 설정
Personal Access Token을 입력하면 day_log 저장소에 자동으로 연결됩니다. 토큰은 이 기기에만 저장됩니다.
발급: GitHub → Settings → Developer settings → Fine-grained tokens
→ day_log 저장소 선택 → Contents: Read and write
이 기기에 남은 사본이 원격과 어긋날 때 씁니다. 저장되지 않은 작성분이 있으면 사라집니다.
